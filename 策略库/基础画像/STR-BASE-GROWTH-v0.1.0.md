# 高成长兑现型 · 试运行 0.1.0

适用于成长预期需要由订单、收入、利润或现金流持续兑现的对象。

| 证据角色 | 内容 |
|---|---|
| 否决项 | 业务兑现证据不足；关键订单/客户被否证；估值锚失效；价格纪律门失败 |
| 主证据 | 订单与收入兑现、利润质量、资本开支、份额变化、E3–E4 业务证据 |
| 确认项 | 盈利预期修正、产业验证、相对强度、机构拥挤与价格接受 |
| 背景项 | 概念关联、远期空间叙事、无收入口径的 TAM |

- 估值锚：PEG、现金流、远期盈利或行业单位经济模型；假设必须显式。
- 默认周期：短周期至波段，不能用远期故事覆盖近期兑现缺口。
- 价格纪律：连续上修预期已被价格加速反映时，等待新的经营差量。
- L2 可调：兑现指标权重、估值消化窗口、产业验证时滞；E0–E2 不得冒充已兑现。
