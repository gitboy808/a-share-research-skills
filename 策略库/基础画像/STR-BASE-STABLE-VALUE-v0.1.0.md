# 稳定价值型 · 试运行 0.1.0

适用于盈利和现金流相对稳定、分红或资产回报可作为主要价值参照的对象。

| 证据角色 | 内容 |
|---|---|
| 否决项 | 盈利质量恶化；现金流与利润长期背离；估值锚过期；价格纪律门失败 |
| 主证据 | 可持续盈利、自由现金流、资本回报、分红能力与资产负债表 |
| 确认项 | 估值分位、利率环境、防御资金、相对强度与回撤承接 |
| 背景项 | 短期题材热度、单次媒体曝光 |

- 估值锚：可比 PE、股息率、自由现金流收益率或 PB，按业务结构选择。
- 默认周期：波段；事件冲击另加战术修饰。
- 价格纪律：估值修复已超出历史动态基线时不能仅以“优质”继续追价。
- L2 可调：估值分位窗口、确认权重、利率敏感度；不得降低现金流真实性要求。
