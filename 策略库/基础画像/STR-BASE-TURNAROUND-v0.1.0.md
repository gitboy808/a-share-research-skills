# 困境反转型 · 试运行 0.1.0

适用于经营、供需或治理处于修复初期，传统静态估值暂时失真的对象。

| 证据角色 | 内容 |
|---|---|
| 否决项 | 持续经营或流动性风险未解除；反转前提被否证；价格纪律门失败 |
| 主证据 | 亏损收窄路径、现金流拐点、产能/价格修复、治理与债务改善 |
| 确认项 | 订单、毛利、库存、相对强度、内部广度与价格接受 |
| 背景项 | 单季度同比改善、一次性收益、纯情绪超跌 |

- 估值锚：正常化盈利、现金流、资产价值或行业单位指标，不强用当期 PE。
- 默认周期：短周期至波段，但必须拆分修复与真正反转。
- 价格纪律：超跌反弹未出现经营确认时不得升级为结构反转。
- L2 可调：拐点确认窗口、现金流/利润权重、风险折价；持续经营风险始终是非补偿性否决项。
