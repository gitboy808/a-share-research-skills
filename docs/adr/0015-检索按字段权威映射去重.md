# 检索按字段权威映射去重

检索投影按照工作流写入所有权为研究字段指定唯一权威产物，并以原子研究单元的稳定引用去重；同一内容出现在报告、镜像、索引、对象档案或最终回答中时，只保留导航与展示关系，不重复计为事实或占用多份投研工作集。相比让所有 Markdown 文档等权参与语义检索，这会限制报告正文直接举证，但能避免重复叙述制造虚假多源印证，并把模型带回证据包、判断日志、规则、经验和策略版本等正式来源。

## Consequences

- 原子事实以证据包为权威，历史判断以判断日志为权威，对象档案只承载带引用的当前视图；发生冲突时仍以不可覆盖的时间流水为准。
- 当前判断、观察池和各类索引只用于定位；调研报告、分析报告与用户叙事输出可以参与导航检索，但不能作为独立证据。
- 运行记录只用于审计流程，不进入事实或方向判断；重复文本不得提高来源独立性、证据覆盖或置信度。
