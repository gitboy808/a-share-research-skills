# 时间流水与对象档案组成双视图记忆

跨会话分析既要保留每次判断发生时的原貌，又要快速取得某个板块或个股的最新认知，因此采用不可覆盖的时间流水作为历史事实源，并以对象档案作为当前认知视图。只保留时间流水会导致新会话检索遗漏，只维护对象档案则容易静默改写旧错误；对象档案必须引用原始判断和报告，不能取代或复制历史流水。

## Consequences

- 对象档案与时间流水可能暂时不一致；发生冲突时以带时间戳的原始流水为准，并将档案标记为待刷新。
- 新会话按研究对象加载相关档案与链接记录，不默认读取全部历史报告。
- 机会扫描另以 `观察池.md` 镜像最多 20 个最高优先级观察候选，全部候选版本保存在 `观察日志/YYYY-MM.md`；候选采用 `CYYYYMMDD-NNN`，与正式判断 ID、判断日志和胜率统计隔离。
