# 文档事实源与可重建检索投影分离

投研系统继续以版本化 Markdown 文档作为唯一事实源，但不再要求模型为每项任务默认通读全部常驻内容；系统增加可从事实源重建的非权威检索投影，先以高召回方式构造有界投研工作集，再按稳定引用核验会影响结论、否决项或冲突处理的原文。相比继续扩大上下文窗口或以摘要替代事实，这一选择增加了检索遗漏与索引陈旧风险，因此必需字段必须有显式覆盖状态，关键原文未核验时只能降级或弃权。

## Consequences

- 结构化对象关系、判断链、证据角色、时效和任务证据清单决定必须加载的内容；语义检索只扩大候选召回，不能证明证据完整。
- 冲突、否证、过期项和否决证据不按语义相似度降权；固定 Top-K 命中不能替代覆盖检查。
- 检索投影必须保留指向事实源的稳定引用；影响结论的候选在使用前回到原文核验。
