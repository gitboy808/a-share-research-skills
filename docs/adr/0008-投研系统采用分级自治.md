# 投研系统采用分级自治

投研系统采用 L0–L3 分级自治：L0 机械记录、L1 按既定门槛演进市场教训、L2 在预先批准的变更预算内进行每周版本化调参，均可自主执行；L3 涉及风险优先、证据底线、弃权原则、双轴复盘、输出边界、错误分类或 skill 架构时只能提案并等待用户确认。相比完全人工审批或无限自我修改，这一边界让系统获得可观的学习自主性，同时防止为追逐近期命中率而拆除安全护栏。

## Consequences

- L2 分为慢速结构参数与快速情境参数。结构参数调整必须声明旧值、新值、样本依据、允许范围、预期影响、影子评估结果和回滚值，并且只能在元复盘窗口晋级；默认最低验证线为 10 个独立证据簇、2 种市场状态和 4 个自然周。
- 情境参数可以在声明的市场状态、主题阶段与短判断周期内即时激活，必须绑定激活条件和自动失效时间；它只能调整情景权重、确认窗口、追高约束和跟踪阈值，不得降低证据底线。首次识别的新情境最高只能以低置信运行，未经慢验证不得推广为结构参数。
- L2 候选先作为影子版本在相同信息快照上并行计算，不影响正式判断；满足预设效果与风险门槛后可自动晋级，晋级后触发回滚条件则恢复旧版本。
- 影子版本按过程完整性、风险错误、概率校准、判断质量、机会效率的顺序比较；后一项的改善不得抵消前一项恶化，尤其不得用提高覆盖率掩盖追高或错误离场增加。
- 来源优先级、非底线型动态阈值和指标权重可以进入 L2；最低证据要求、低于 55% 弃权等原则属于 L3。
- 数据源不可用等运行故障可以在预先批准的备用集合内即时切换，不视为参数版本晋级。
- 所有自主变更必须可追溯、可回滚；超出预授权范围时自动降级为 L3 提案。
