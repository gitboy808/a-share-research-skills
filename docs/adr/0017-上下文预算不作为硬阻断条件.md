# 上下文预算不作为硬阻断条件

投研系统不以 token 数量或上下文占用比例作为强制中止、强制拆段或禁止持久写入的硬执行边界；工作流能否继续由任务证据清单、证据门槛、信息快照和写入权限决定。相比在固定阈值处失败关闭，这避免不同模型窗口、任务复杂度和临界估算误差造成研究被机械截断，但要求系统通过检索投影、阶段隔离、来源载荷外置和去重主动控制上下文增长，不能把“不设硬边界”解释为允许无界装载。

## Consequences

- 上下文占用可以成为监测指标、优化信号或续段建议，但不能单独改变研究状态、置信区间或证据完成度。
- 工作集预算可以自动减少重复视图、延迟展开背景正文、优先使用稳定引用，并建议或启动可逆的干净续段；这些动作不得强制中止任务。
- 不得为了满足软预算而删除任务证据清单中的必需项、冲突、否证或关键核验片段。
- 平台自动压缩产生的摘要仍不是证据；压缩发生后，影响结论的原子研究单元必须按稳定引用重新核验。
