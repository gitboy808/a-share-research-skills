# 文档事实源配合轻量校验脚本

投研系统继续以版本化文档作为唯一事实源并保留常驻层、归档层及体积约束，同时允许 skill 套件提供只处理 schema、唯一 ID、链接、版本链和派生索引的确定性校验脚本；脚本不得解释行情、选择策略、形成判断、修改经验或无痕修复内容。本决策取代 ADR-0001 的“现阶段纯文档且暂缓脚本”限制，但保留其拒绝数据库主事实源和无人值守调度的理由。

## Consequences

- 校验脚本默认只读并报告错误；需要重建派生索引时必须以文档事实源为输入，且不能改写原始证据和判断。
- 行情数据采集、模型判断和定时调度不因本决策自动获准；未来无人值守运行仍需独立决定失败恢复与快照边界。
- 常驻层体积限制继续有效，脚本不能以生成大型启动索引绕过上下文预算。
