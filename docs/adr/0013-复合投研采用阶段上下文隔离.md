# 复合投研采用阶段上下文隔离

`investigate → analyze` 等复合任务在编排上共享运行 ID，但每个专用工作流使用独立的阶段上下文，只以正式产物、稳定引用和运行清单交接；网页原始回传、终端输出和临时推理不跨阶段传递。相比在一个长会话中连续完成全部工作，这会增加阶段启动与显式补证成本，但能限制上下文增长、防止分析依赖未写入证据包的印象，并使证据包交接契约真正可审计。

## Consequences

- 分析阶段只消费证据包、任务证据清单、相关判断链与所需原文；不得继承调研工具历史。
- 分析发现关键缺口时返回增量调研请求，由路由器启动新调研快照；调研结束后重新构造分析上下文。
- 最终组合只读取各阶段正式状态和产物，不把阶段上下文合并为新的事实或判断格式。
