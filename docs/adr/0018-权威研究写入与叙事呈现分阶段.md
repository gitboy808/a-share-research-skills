# 权威研究写入与叙事呈现分阶段

调研和分析阶段先完成紧凑的权威研究单元、字段差量与引用校验，再结束研究上下文；调研报告、分析报告和用户回答由独立的呈现上下文根据这些稳定引用生成，不继承研究阶段的工具历史，也不得新增事实、改变判断、补搜或调整置信区间。相比在同一上下文中同时研究、写入多份事实视图并生成长报告，这增加了呈现校验和阶段启动成本，但能防止报告正文与大块文件差异反向膨胀研究上下文，并允许报告失败后从权威产物安全重建。

## Consequences

- 呈现投影必须引用存在的原子研究单元；数字、状态和概率区间以权威产物为准。
- 呈现失败不使已校验的证据包或判断失效；重建报告不得生成新的研究版本。
- 报告可以解释和重组，但同一稳定引用的不同呈现不得改变其研究语义。
