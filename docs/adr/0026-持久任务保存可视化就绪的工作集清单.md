# 持久任务保存可视化就绪的工作集清单

凡产生正式证据、判断、复盘或策略变更的任务，都在运行记录中保存紧凑工作集清单，记录阶段快照、任务契约与策略版本、投影版本和哈希、装配的原子研究单元、选择原因、原文核验状态、覆盖与缺口、adapter 降级及上下文规模；只读任务不落盘，清单不复制来源载荷、报告正文或模型推理。相比只保存最终产物 ID，这增加了少量审计数据，但能区分召回遗漏、核验遗漏和推理错误，并为后续证据图、判断链、覆盖热力图、时效视图和上下文成本可视化提供稳定数据基础。

## Consequences

- 清单使用稳定节点 ID、受控关系类型、时间字段、覆盖状态和选择原因，未来可视化从这些结构字段派生，不解析报告自然语言。
- 同一原子研究单元在清单中只记录一次，可关联多个进入原因；内容正文仍由字段权威映射定位。
- 工作集规模、来源载荷外置量、hydrate 数量和投影降级状态属于运行质量数据，不参与方向置信度。
