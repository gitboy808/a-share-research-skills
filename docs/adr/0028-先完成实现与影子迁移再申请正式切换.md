# 先完成实现与影子迁移再申请正式切换

本轮在本仓库完成新架构、工作集装配 module、任务契约、检索投影、迁移工具、skill/schema/模板/校验器改造与测试。任何历史工作区都只能作为只读输入，在独立输出目录完成影子迁移和会话回放；影子验收通过后，正式工作区的一次性无兼容切换仍需用户另行确认。

## Consequences

- 影子迁移使用独立路径，所有结构改写、ID 映射和校验报告都留在副本或当前项目的测试产物中。
- 可以只读检查用户明确指定的历史工作区和会话以建立基线；迁移工具必须写入另一个新目录。
- 正式切换请求必须给出影子验收结果、未解决差异、恢复方式和精确目标路径。
