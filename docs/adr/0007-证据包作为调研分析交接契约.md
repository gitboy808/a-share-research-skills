# 证据包作为调研分析交接契约

调研工作流必须输出绑定信息截止时间的版本化证据包，分析工作流只能消费通过最低完整性校验且未过期的证据包；缺少关键证据时由统一入口先调研，直接运行分析则停止形成方向判断或正式弃权。相比允许分析过程中无痕补搜，这一强制交接增加了一次结构化记录，却让来源、口径、冲突和事后信息污染可以被复盘审计。

## Consequences

- 证据包至少记录已确认事实、独立来源、数据口径、冲突与否证、关键缺口、档案过期项及差量变化。
- 包内事实拆成有唯一项 ID 的原子证据，分别记录确认状态、来源链、事件与发布时间、数据口径、关联对象及过期条件；推测和叙事信号必须分区，不能伪装成事实项。
- 每个证据项独立声明时效，证据包不使用统一过期时间；分析依据阶段和策略画像列出必需字段，关键项过期时由入口刷新或由直接分析停止形成方向判断。
- 证据包作为独立 Markdown 产物按月归档并分配唯一 ID，可覆盖多个相关对象；对象档案、报告和判断引用具体证据包或证据项，不复制为新的事实源。
- 证据包版本不可回写；补充材料必须生成后续版本并保留原截止时间。
- 只有产生新增事实、刷新档案或进入分析判断链的调研才强制落盘，普通浏览不制造空证据包。
- 分析结果必须引用所消费的证据包版本，复盘可以据此区分调研缺陷与推理缺陷。
