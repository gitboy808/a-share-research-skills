# 来源载荷外置并按需核验

网页、PDF、行情接口和终端产生的完整来源载荷默认保存在阶段上下文之外，主调研上下文只接收来源元数据、候选原子事实、有界核验片段、口径、冲突提示和可继续定位的引用；准备写入证据包、触发否决或处理冲突的候选必须按引用回到原始片段核验。相比把完整工具回传持续累积在主上下文中，这增加了临时缓存、内容一致性和定位管理，但能扩大调研覆盖而不让每次模型调用重复携带全部原始材料，也避免把代理摘要直接当成事实。

## Consequences

- 来源载荷不是文档事实源，按阶段保留并有明确生命周期；检索投影只索引其定位信息和候选关系。
- 主调研者仍对正式证据负责；候选总结、搜索摘要和自动抽取结果不能替代核验片段。
- 来源内容无法重新定位、内容一致性失效或口径不能确认时，候选只能标记未证实、冲突或不可取得。
