# 历史产物彻底结构迁移并移除兼容

现有历史报告、证据、判断、复盘和对象记录一次性重写为最新 schema、稳定引用、字段键和目录关系，迁移完成后删除 legacy 解析与运行时兼容；结构可以彻底改变，但旧命题、当时信息快照、来源状态和未知项必须保持原义，新增而当时缺失的字段只写“当时未记录”，禁止用当前知识补齐。相比永久保留旧格式只读分支，这会增加一次性迁移与验证成本，却能让检索投影、工作流和校验器只服务一套最新设计，同时保留真实的历史决策过程。

本决策取代 ADR-0005 与既有架构中“历史原文不改写、校验器继续兼容旧 schema”的结构兼容要求，但不取代 ADR-0004 的信息快照不可回写原则。

## Consequences

- 迁移必须保存旧引用到新稳定引用的映射、迁移前后内容哈希和字段缺失说明；旧格式只通过 Git 历史及迁移清单追溯。
- 迁移完成并验收后，skill、模板、schema、校验器和检索 module 不再包含 legacy 分支。
- 任何无法证明语义等价的历史字段不得猜测转换；应明确标记当时未记录或迁移不可判定。
