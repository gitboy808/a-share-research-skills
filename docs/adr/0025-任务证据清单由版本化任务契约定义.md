# 任务证据清单由版本化任务契约定义

系统为不同工作流、对象类型和阶段维护版本化任务契约，声明固定证据底线、条件要求、允许未知和阻断语义；投研工作集装配根据运行清单、契约版本与策略版本实例化本次任务证据清单，模型可以增加补证需求但不能删除基础要求。相比让模型依据已检索结果临时决定“还需要什么”，这增加了契约治理与版本维护，却能把证据完整性独立于语义排序，并使回放测试直接验证必需覆盖。

## Consequences

- 基础任务契约属于 L3，修改证据底线需要用户确认；策略画像可以增加条件项和时效要求，但不得降低基础底线。
- 运行记录固定任务契约版本、策略版本及其生成的任务证据清单；字段允许未知时仍须记录缺口及影响。
- 任务契约不是输出模板，也不包含事实或方向判断；它只定义进入某类研究结论前必须检查的输入条件。
