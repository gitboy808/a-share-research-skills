# 并行调研由主 agent 单点核验落盘

复杂调研可以由 subagent 按外围市场、产业政策、公司事实、行情结构和反方证据等不重叠方向并行收集候选原子证据，但 subagent 不直接修改证据包、对象档案或判断记录；主 agent 负责核验关键来源、去除同源转载、统一数据口径并单点写入正式事实源。相比多 agent 直接并发写入，这一模式牺牲少量合并速度，却避免重复证据、写入冲突和局部信息直接变成正式结论。

## Consequences

- 简单调研不强制并行；是否拆分由任务复杂度和来源覆盖需要决定。
- subagent 输出属于候选材料，不得单独形成正式判断或更新持久记忆。
- 主 agent 对最终证据包的来源独立性、口径一致性与缺口披露负责。
