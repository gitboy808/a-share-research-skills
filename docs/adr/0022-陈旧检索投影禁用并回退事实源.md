# 陈旧检索投影禁用并回退事实源

投研工作集装配在使用检索投影前核对 schema 版本、相关事实文档内容哈希与原子单元解析状态；发现不一致时先增量重建，重建失败则禁用陈旧结果并直接读取相关 Markdown，同时在运行清单标记 `projection_degraded`。相比索引异常时完全停止研究，这保留了事实源直读能力；相比继续使用旧索引，它避免把未命中误判为证据不存在。索引更新发生在权威文档写入和校验之后，失败不回滚已校验文档。

## Consequences

- 内容一致性使用内容哈希而非修改时间；索引结果携带对应事实源版本或哈希。
- 降级直读可能扩大阶段上下文，但只能影响效率，不能改变证据完成度、研究状态或置信区间。
- schema 变化、关系不一致或增量解析无法闭合时执行全量重建；缓存删除后也必须得到等价投影。
