# 投研工作区作为唯一事实源

第一版投研 skill 套件绑定当前投研工作区，由工作区中的领域词汇、研究规则、经验库、判断流水和对象档案共同构成唯一事实源；skill 只维护流程和读写契约，不复制这些内容。相比立即追求可独立搬运的自包含 skill，这一选择牺牲了短期可移植性，但避免双份规则、经验串库与跨会话状态分叉，并为以后通过显式工作区适配边界抽取可移植核心保留空间。

## Consequences

- 第一版不得在 skill 内复制 `CONTEXT.md`、`研究规则.md`、`经验库.md` 或对象档案内容。
- `模板/` 是扫描、调研、分析、判断、复盘、对象档案、策略与元复盘输出的唯一模板源；skill 只引用模板，不保留副本，旧模板直接升级到当前 schema。
- skill 找不到或无法验证投研工作区时必须停止写入，而不是创建一套隐式的新历史。
- 未来跨工作区运行必须显式选择目标工作区，并重新验证经验和判断的适用范围。
