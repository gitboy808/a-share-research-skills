# 统一入口与专用投研工作流

投研 skill 采用一个薄入口编排扫描会话、调研会话、分析会话、复盘会话和元复盘，五个专用工作流分别承担机会发现、事实核实、形成判断、双轴验证与周期性学习；证据标准、判断结构和输出契约作为共享资源维护。相比继续扩充单体 `fenxi` 或让多个技能各自复制规则，这一结构在保留统一使用入口的同时，隔离了不同成功标准和写入权限，减少上下文膨胀与规则漂移。

## Consequences

- 调研与分析工作流都覆盖大盘、外围传导、产业链、交易主题与个股，不按研究对象机械拆分；不同对象的核查清单按需加载为共享参考资源。
- 扫描工作流面向宽范围机会发现，输出有确认、失效和时限的观察候选；候选不进入判断日志，触发后仍须依次经过调研与分析。
- 调研工作流可以独立刷新事实证据与对象档案，不得为了完成流程而强制生成方向判断或写入判断日志；分析工作流消费其已核实证据。
- 分析工作流以盘前、竞价、盘中、突发事件和非交易时段专题作为阶段参数，共用判断链与快照规则，不为各时段创建独立 skill；盘后结果验证仍由复盘工作流独占。
- 复盘与元复盘不并入分析工作流，避免盘后信息污染盘前判断，也避免单日样本直接改写经验；复盘除到期触发外，只能在预设证伪、官方否证或数据污染已发生时提前介入，普通观点变化由分析工作流追加版本。
- 统一入口默认按自然语言投研意图自动触发，同时提供显式命令用于意图模糊时强制指定流程；用户不需要记忆专用工作流名称。
- “核实、梳理资料”等事实请求路由到调研；“分析、上涨逻辑、持续性”等方向请求先调研后分析；盘前、竞价、盘中和事件请求使用对应分析阶段；复盘与元复盘按词义直达。仅说“看看、研究一下、了解一下”时默认只调研，不自动生成判断。
- 扫描在用户显式要求、盘前候选刷新、盘中大盘或轮动分析、以及复盘检测到拥挤方向衰减后触发；单一对象请求只检查直接替代关系，不默认全市场扫描。当前保持用户触发并仅保留未来调度接口。
- 统一入口可以按依赖顺序组合多个工作流，但专用工作流不得相互越权；例如“复盘后前瞻”必须先冻结旧判断的复盘快照，再以新的信息截止时间形成新判断和新 ID。
- 各专用工作流拥有强制核心 schema 和按需展示章节，缺失必填项必须显式记录；统一入口只组合既有产物，不生成新的事实或判断格式。
- 各工作流按职责独立评价：扫描看发现与漏检，调研看证据质量，分析看风险和校准，复盘看验证完整性，元复盘看真实改进，入口看路由与隔离；局部指标不能抵消系统级风险恶化。
- 新套件采用 `a-share-research`、`a-share-scan`、`a-share-investigate`、`a-share-analyze`、`a-share-review` 与 `a-share-meta-review` 六个 skill，并集中存放在同一套件目录。
- 套件根目录固定为 `.agents/skills/a-share/`，六个 skill 各自拥有独立的 `SKILL.md` 与 `agents/openai.yaml`；套件根目录不是第七个可触发 skill。
- 五个专用 skill 均可被直接调用以便精确使用和独立测试，统一入口仍承担默认语义路由与复合编排；直接分析缺少有效证据包时必须停止形成方向判断或正式弃权，不得无痕兼任调研。
- 所有专用 skill 执行共享预检；由入口编排时复用入口生成的运行清单，直接调用时自行检查工作区、schema、输入版本与写入目标并输出开工简报。关键文件缺失或不兼容时停止写入。
- 只有产生观察候选、证据包、判断、复盘或策略版本等持久写入的任务才保存按月归档的运行记录；复合任务共享运行 ID，但每个工作流阶段保持独立信息快照。
- `AGENTS.md` 收缩为薄启动协议，只保留语义入口、工作区事实源、L3 风险护栏、写入与自动化边界；专用步骤只存在对应 skill 和共享 schema，规范性研究知识继续由 `研究规则.md` 持有。
- 现有 `fenxi` 不设兼容入口，实施时完整移除，避免其旧 ID、旧评分、弃权不记分和直接买卖结论继续被触发。
- 历史报告、判断流水和复盘原文保持不可覆盖；当前索引与对象档案可以升级，但旧记录缺失的新字段只能标记“当时未记录”，不得事后回填。校验器可读取明确标记的历史 schema，新 skill 只能生成当前 schema。

## Write ownership

| 工作流 | 可以写入 | 不得写入 |
|---|---|---|
| 统一入口 | 编排记录与组合报告 | 证据、判断、经验或参数事实源 |
| 扫描 | 观察候选、扫描报告 | 正式证据包、判断、经验或参数 |
| 调研 | 证据包、对象档案事实字段、调研报告 | 判断结果、教训状态、策略参数 |
| 分析 | 判断日志、当前判断、对象档案分析字段、分析报告 | 回写证据、旧判断评分、经验升级 |
| 复盘 | 结果轴、过程轴、错误归因、证据簇、当前判断移除、复盘报告 | 改写原判断、教训升级、参数调整 |
| 元复盘 | 市场教训状态、策略版本、校准统计、周收敛报告 | 改写历史证据包或判断快照 |

官方否证或数据污染可以触发追加式暂停记录，但不能成为任何工作流回写原文的例外。

## Acceptance

实施必须在隔离工作区通过十类前向测试：模糊请求仅调研；过期证据先刷新或弃权；已计价利好被价格纪律门拦截；低热度候选只进观察池；直接分析不得越权调研；复盘执行双轴且不日内升级教训；元复盘只在 L0–L2 自治；复盘后前瞻隔离快照；旧 schema 只读且新输出不回退；六个 skill 触发描述互斥。测试使用合成行情与隔离副本，最终真实任务只读验证来源流程，不写入真实判断日志。
