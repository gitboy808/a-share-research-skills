# 影子回放验收后无兼容切换

新检索与上下文架构先在隔离副本完成影子迁移，并以冻结快照回放代表性调研、分析、事件、复盘、扫描及冲突案例；质量和上下文指标通过后才一次性迁移正式工作区并删除 legacy 分支，不长期双轨运行。相比直接重写正式历史，这增加了隔离迁移和对比成本，但能在不污染事实源的前提下证明结构迁移保持原义、检索没有漏掉关键证据，并确认被验收会话满足其预先声明的上下文目标。

## Acceptance

- 任务证据清单必需项召回率 100%，否决项、冲突、否证和过期条件零遗漏；报告重复不得形成独立来源，历史快照不得混入未来信息。
- 新旧文字可以不同，但原子命题、快照、证据关系与研究状态差异必须可解释；更强结论必须绑定新增证据。
- 每个回放套件必须绑定自己的会话身份和可复核 telemetry，并在看到候选结果前声明原始载荷降幅、主上下文比例和峰值 token 上限；缺少实测事件时验收失败。

这些套件目标是发布验收条件，不是投研运行时的硬执行边界。
