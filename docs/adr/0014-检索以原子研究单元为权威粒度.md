# 检索以原子研究单元为权威粒度

检索投影以具有稳定身份的原子研究单元作为可进入投研工作集的最小粒度，Markdown 文件继续作为人类可读的事实容器；任意文本分块和语义向量只负责发现候选，不能脱离所属原子单元直接支撑判断。相比文件级读取或自由分块，这要求证据项、判断版本、对象字段、规则、策略和映射保留可定位的身份与时间边界，但能避免为取得一个事实加载整篇产物，也不会切断事实、来源、时效、冲突和证据角色之间的关系。

## Consequences

- 检索单元保留稳定引用、类型、对象、字段、信息快照、状态、过期条件、证据角色、原文定位和关系。
- 证据项与判断继续使用既有 ID；缺少独立 ID 的对象字段和映射需要形成稳定引用规则，但不得因此把派生索引升级为事实源。
- 语义命中的文本必须解析回所属原子研究单元，并在进入判断链前核验原文。
